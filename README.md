# CampusHub Study Portal

A responsive college website for students to access:
- syllabus
- notes
- previous year question papers
- department-wise academic resources

## Features
- modern landing page
- filterable resource cards
- student-friendly layout
- responsive design for desktop and mobile

## Run locally
Open `index.html` directly in a browser, or use a small local server such as:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Project structure
- `index.html` — main page layout
- `styles.css` — styling and responsive design
- `script.js` — dynamic resource filtering
